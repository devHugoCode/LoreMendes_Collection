# Lore Mendes Collection

Landing page de uma loja de moda fitness feminina.

## 🚀 Tecnologias

* HTML5
* CSS3

## 📌 Sobre o projeto

Projeto desenvolvido durante meus estudos de desenvolvimento web, com foco na prática de HTML e CSS e na criação de uma página moderna para uma marca de moda fitness feminina.

## 🎯 Objetivo

Praticar estruturação de páginas HTML, estilização com CSS, imagens, botões e organização de arquivos.
